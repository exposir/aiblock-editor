# 块编辑与 Markdown

## 块编辑

| 核心能力 | 在编辑器里怎样用 |
| --- | --- |
| 块标识与大纲 | 用标题生成左侧大纲。块菜单可复制块链接。 |
| 容器与分栏 | 用 Callout 放操作提示，用 Toggle 收起细节。多栏最多五列，拖动分隔线调整列宽。 |
| 块拖拽 | 拖动块把手上下调整顺序，拖到允许分栏的左右边缘创建或加入列。 |
| 多块选择 | 在正文边缘拉框，或用 `Esc` 进入块选区，再用 `Shift` 加方向键扩展。 |
| 斜杠菜单与格式 | 键入 `/` 或 `、`，用中文、拼音或英文找块。划词后可格式化或发起评论。 |
| 表格与代码块 | 表格支持行列编辑，代码块支持语言选择、换行和复制源码。 |

段首键入 `[! ` 创建提示块，键入 `>> ` 创建折叠块。末尾空格会触发转换。这两个输入快捷键用于编辑器内键入。

## Markdown 往返

在工具栏导入 Markdown 文件，或把 `.md` / `.markdown` 拖到正文区域以新建页面。符合 Markdown 结构的纯文本粘贴可解析为块。从菜单导出 Markdown、导出 JSON 或复制整页 Markdown。

Markdown 编解码覆盖标题、列表、任务列表、引用、代码、表格及图片。原生 JSON 用来保留正文中的编辑器字段。Markdown 文本省略内部块 ID 和评论标记，部分语法会在导出时规范化。

| 扩展块 | 持久语法 |
| --- | --- |
| Callout | `> [!NOTE]` 加引用正文，可选图标。还支持 `TIP`、`WARNING`、`CAUTION`、`IMPORTANT`、`INFO`。 |
| Toggle | `<details open>` 或 `<details>`，包含独占一行的 `<summary>标题</summary>` 与正文。 |
| 多栏 | `::::columns` 包裹各个 `:::column{width=60}` 小节，每栏以 `:::` 结束，外层以 `::::` 结束。 |
| Mermaid | 语言为 `mermaid` 的代码围栏。 |
| KaTeX | 行内 `$…$`，块级独占行的 `$$…$$` 或 `math` 代码围栏。 |
| 图片 | `![替代文本](https://…)` 或 `![替代文本](asset:…)`。编辑器还可用 `<img>` 保留尺寸与布局。 |

完整示例与纯 Node CLI 的图片导入边界见 [CLI 参考的 Markdown 扩展块](../reference/cli-api#markdown-扩展块)。

## 图表与公式

用 `/mermaid` 或 `/流程图` 插入图表，切换预览、分栏或源码视图。编辑器调用 Mermaid 原生渲染器，按需加载图种。内置示例覆盖流程图、时序图、状态图、类图、实体关系图、甘特图、思维导图、GitGraph、饼图和 XY 图。工具栏可以套用模板、复制源码或导出 SVG。

用 `/math` 插入块公式，行内可键入 `$…$`。KaTeX 负责预览。打开「全图种与公式复杂示例」可以看到矩阵、分段函数和多行对齐公式。

## 批量贴图

可从剪贴板粘贴、拖放或通过 `/图片` 选取 PNG、JPEG、GIF 或 WebP。单批上限 200 张，单张上限 32 MiB。一个批次对应一个插入步骤，可一步撤销和重做。坏图或解码超时会单独提示，成功的图片仍可插入。

图片按字节内容的 SHA-256 去重，正文引用资产 ID。导出 Markdown 时，`asset:` 引用仍指向原工作区的资产。把 Markdown 交给另一工作区时，需要同时准备对应图片资源。外链图片可以用 HTTP 或 HTTPS 的图片地址。
